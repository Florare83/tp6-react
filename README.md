* Descripción:
El presente proyecto de React + Vite incluye componentes base, Card reutilizable con props, Contador interactivo, Formulario con preview en vivo, Lista de productos con filtrado y To-Do App.

* Tecnologías utiizadas:
React, Vite

* Instrucciones:
1) Crear proyecto React: 
npm create vite@latest tp6-react -- --template react
2) Entrar a la carpeta del proyecto: 
cd tp6-react
3) Instalar las dependencias: 
npm install
4) Iniciar el servidor de desarrollo: 
npm run dev
5) Abrir la URL en el navegador
